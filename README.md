# تطبيق الموارد البشرية — [اسم الشركة] (Flutter)

عربي RTL + FR/EN • iOS وAndroid • أدوار: موظف / مدير / HR / مشرف رئيسي

## التشغيل
```bash
cd hr_app
flutter pub get
flutter run
```
للدخول: أي رقم وظيفي + أي كلمة مرور، واختر الدور من شاشة الدخول (جرّب **مشرف رئيسي** للوصول الكامل). البصمة عبر `local_auth`.

## ما تم بناؤه
- تسجيل دخول آمن + بصمة/وجه + اختيار الدور واللغة
- الرئيسية: إعلانات، إشعارات Push (بنية)، اختصارات بيد واحدة
- الملف: بيانات + وثائق + شهادة عمل PDF
- الإجازات: طلب/رصيد/حالة/قبول-رفض (مدير/HR) + تقويم الفريق
- الحضور: GPS/QR + سجل شهري
- الراتب: كشوف + تحميل PDF مشفر
- الطلبات: إذن خروج/سلفة/شهادة راتب + تتبع + موافقة المشرف
- التدريب/الأداء/التوظيف الداخلي/الدليل/تواصل HR + أسئلة شائعة
- **لوحة Super Admin**: إحصائيات، مستخدمون (إضافة/تعديل/تعطيل/حذف)، أدوار وصلاحيات، موافقات، أقسام وسياسات، إعلانات جماعية، تصدير PDF/Excel، سجل تدقيق Audit Log، الهوية البصرية واللغات والنسخ الاحتياطي
- **إضافة العمال**: نموذج كامل + وثائق + حساب دخول تلقائي + استيراد Excel/CSV + نقل/إنهاء مع حفظ السجل + مدير مباشر ورصيد إجازات
- تقني: عمل جزئي دون إنترنت (مزامنة لاحقة)، تشفير (Secure Storage + HTTPS)، سجل تدقيق، ربط API (انظر `lib/core/api.dart`)، وضع داكن، خط Cairo

## التخصيص قبل الإطلاق
1. ضع اسم الشركة والشعار والألوان في `lib/screens/login.dart` و`lib/core/theme.dart`
2. اربط `HrApi.baseUrl` بنظام HR الحالي + مفاتيح FCM
3. فعّل `flutter_secure_storage` للرموز و`geolocator` بصلاحيات الموقع وQR
4. راجع سياسة الخصوصية للوثائق والرواتب
